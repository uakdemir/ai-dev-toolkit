Code review runs on Opus · max in FULL and on Opus · high in LIGHT. The flags below pin that for
every review agent, whatever model and effort this session is at.

Tier first, one line with a reason. Use the tier already stated in this conversation. If none: FULL
if the commits touch deletion/erasure/retention, authentication/identity, billing/entitlements, a
migration or schema, a security boundary, terraform, legal or consent copy, or a cross-package public
surface — or exceed ~400 production lines, or are hard to reverse. MECHANICAL if there is no
behaviour change. Otherwise LIGHT. When unsure, take the higher tier.

- FULL: run /ai-dev-tools:review-code --max-iterations 1 --effort max --fix-effort max --model opus
  — one round.
  Scope: the commits from this branch, including any mechanical sweeps. review-code has no
  fact-checker, so run ONE fact-check agent between the reviewer and the fixer, dispatched as
  `subagent_type: ai-dev-tools:max-effort` with `model: opus`: per finding, a verdict (confirmed /
  partial / refuted / unverifiable), a correction, and a fix class (unambiguous / needs-decision).
  Reviewer, fact-checker, fixer — no other agents.
- LIGHT: the same round with --effort high --fix-effort high in place of the max flags. Keep
  --model opus, and run no fact-check agent.
  Before fixing any Critical or High finding, verify it yourself against the diff and quote the
  line.
- MECHANICAL: no review agents. Re-run the instrument that proves the change and quote its output.

Required checks for this round, in every tier:
  - Stale references: where the diff deletes or renames a shared concept, search for documents that
    still reference it — specs, runbooks, lane briefs, TASKS.md — and report each as a finding.
  - Do not accept the implementer's summary as evidence of coverage. Verify against the diff.

FULL and LIGHT: fix the unambiguous wins yourself. For ambiguity: group by similarity, write a
brainstorming prompt with alternatives, pros/cons and a recommendation, record my answers, then fix
those too.

Finish with the Critical / High / Medium counts for THIS round only.
